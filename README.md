# RSVP読書

PDFから本文を抽出し、単語・文節単位で順に表示するRSVP読書用のWebアプリです。日本語UIのオフライン対応PWAとして動作します。

## 主な機能

- PDFからテキストを抽出し、読みやすい単位に分割
- RSVP再生、速度調整、前後移動、先頭移動、位置ジャンプ
- 本文全体の表示と、タップした位置からの再生
- IndexedDBで本、読書位置、再生速度を端末内に保存
- ライブラリから本の名前変更・削除
- Service Workerによるオフライン利用

## ローカルでの起動

ES Modules、IndexedDB、Service Workerを使うため、`file://` で直接開かず、ローカルHTTPサーバーで配信してください。Pythonがある場合はリポジトリのルートで次を実行できます。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。Service WorkerはHTTPSまたはlocalhostなどのセキュアコンテキストで利用できます。

## デプロイ

アプリ自体にビルド工程はありません。Cloudflareで `main` ブランチへのpushをトリガーに自動デプロイします。

## 保存データについて

保存先はブラウザごとのIndexedDBです。データは同じブラウザ・同じオリジンで共有され、別端末とは同期されません。ブラウザのサイトデータ削除やストレージ逼迫により、本や読書位置が失われる場合があります。
